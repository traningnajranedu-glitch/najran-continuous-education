# المساعد التعليمي الذكي-الادارة العامة للتعليم بمنطقة نجران 

هذا المشروع يستخدم Next.js + Supabase، ويحتوي على:
- صفحة عامة للاستعلام برقم السجل المدني.
- لوحة إدارة محمية بتسجيل دخول.
- إضافة وتعديل وحذف المرشحين.
- تعديل حالة الترشيح ورسالة الترشيح.
- استيراد ملف Excel مباشرة من لوحة الإدارة.

## خطوات التشغيل
1. أنشئ مشروعًا في Supabase.
2. من SQL Editor شغّل ملف `supabase.sql`.
3. من Authentication > Users أنشئ مستخدم الإدارة بالبريد وكلمة المرور.
4. في Vercel أضف المتغيرين الموجودين في `.env.example`.
5. انشر المشروع.
6. صفحة الاستعلام: `/`
7. لوحة الإدارة: `/admin`

## استيراد Excel
من لوحة الإدارة اضغط "استيراد Excel". يجب أن تكون الأعمدة بالترتيب:
م | الاسم | سجل المدني | مدرسة الترشيح
وسيتم وضع الحالة الافتراضية "مرشح".
